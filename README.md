# Open

Suite créative libre et locale pour Windows, par [StudioGLSC](https://studio.glsc.fr).

- [`pics/`](pics/) — **OpenPics**, éditeur d'images (GPL-3.0-only)
- [`site/`](site/) — pages statiques de `open.glsc.fr` : accueil de la suite et page de téléchargement de chaque module

Le site est constitué de fichiers statiques à déposer tels quels sur le serveur. La page de téléchargement d'un module lit un fichier `releases.json` placé à côté des binaires (format dans [`pics/docs/PHASE1.md`](pics/docs/PHASE1.md)) et n'affiche aucun lien tant qu'il n'existe pas.
