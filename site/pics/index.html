Module Pics

OpenPics, l'éditeur d'images libre.

Calques, sélections, retouche et filtres, pour Windows 10 et 11 (x64). Tout se passe sur votre machine : pas de compte, pas de télémétrie.

Configuration

  • Windows 10 ou 11, 64 bits.
  • Carte graphique compatible DirectX 12 ou Vulkan recommandée (repli processeur sinon).
  • Installeur : s'installe pour l'utilisateur. Portable : un dossier à décompresser, rien n'est écrit ailleurs.

Les premières versions ne seront pas signées : Windows SmartScreen peut afficher un avertissement. Vérifiez l'empreinte ci-dessus avant de lancer le fichier.
